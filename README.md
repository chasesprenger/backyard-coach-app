## 🚀 Instant Download & Installation

### 🍏 macOS (Apple Silicon & Intel)
1. Download the latest installer: [**`Backyard Coach-1.0.0-arm64.dmg`**](https://github.com/chasesprenger/backyard-coach-app/releases/latest)
2. Double-click the `.dmg` file.
3. Drag **Backyard Coach** into your **Applications** folder.
4. Launch **Backyard Coach** from Launchpad or Spotlight.
   > *Note for macOS Gatekeeper*: On first launch, if macOS alerts you that the developer is unverified, simply right-click (or Control-click) the app icon and select **Open**, then click **Open** in the dialog.

### 🪟 Windows
1. Download the installer: [**`Backyard-Coach-Setup-1.0.0.exe`**](https://github.com/chasesprenger/backyard-coach-app/releases/latest)
2. Run the installer and follow the on-screen prompts.
3. Launch Backyard Coach from your Start Menu or Desktop shortcut.

## ⚡ Core Features

- **Tactical Situational Playcaller**: Dynamic play calling recommendations driven by down, distance, field zone, and time remaining.
- **Wireless Sideline-to-Huddle Sync**: Instantaneous play transmission from the sideline coach device directly to the quarterback's on-field wristband.
- **Zero-Drift Referee Clock**: Live synchronized game clocks, play clocks, instant timeout call broadcasting, and `+15s` extension syncing across all sideline devices.
- **Multi-Screen Defensive Playbook**: Formation showcase hubs, vector chalkboard schematic previews, situational defense scores, and pre-snap coverage audibles.
- **Full League & Tournament Hub**: Standings, automated schedules, commissioner code controls, team enrollment, and multi-team record keeping.
- **Synthesized Retro Audio**: Zero-latency 8-bit chiptune audio synthesized using the Web Audio API.
